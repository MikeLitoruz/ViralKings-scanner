# Manual OneDrive ↔ Windows Viral Scanner V6.2.5\n\n1. iPhone: run discovery in Brave, results saved in local browser IndexedDB.\n2. Select videos, Downloads → Save queue; use iOS Files / OneDrive to save job-....json inside OneDrive/Viral Scanner/Queue.\n3. Windows: START-VIRAL-SCANNER.cmd starts the native scanner and mobile-desktop-bridge.mjs watcher when Node and OneDrive are available.\n4. Windows bridge downloads using the existing desktop Telegram authorization (which must be separately configured in the Windows scanner) or yt-dlp for YouTube. It verifies 4K60 SDR MP4 and publishes in OneDrive/Viral Scanner/Videos/<profileId>, with JSON status in Status/.\n5. In the mobile Results tab, Export scan runs to OneDrive; place mobile-runs-*.json in OneDrive/Viral Scanner/Runs; the bridge imports these as provisional into data/mobile-imported-runs without modifying desktop current, archive or rankings.\n6. In the mobile Downloads tab, load a Status/job-....json file from OneDrive to see the Windows result without Microsoft Entra.\n\nThis workflow uses manual file sharing and the installed OneDrive clients, not Microsoft Graph. Files must be saved in the specified OneDrive folders. Don't put Telegram secrets or browser sessions in OneDrive or GitHub.\n
