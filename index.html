Telegram

Telegram not connected. Sign in once using your own Telegram API credentials; then unlock the encrypted Telegram session on this device.

Your Telegram session and API settings are encrypted locally using your passphrase. The unencrypted session stays in memory only while connected and is never uploaded to OneDrive. Connect uses Telegram's own API, not a bot. Only sign in on an HTTPS host you control. Signing out in Telegram Settings also revokes the session.

YouTube Data API

An API key with YouTube Data API v3 enabled is required. The key is not uploaded to OneDrive.
